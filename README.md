# CSS Animation and Opacity Demo

A simple front-end project developed using HTML and CSS to demonstrate CSS animations and the opacity property. This practical assignment showcases a bouncing ball animation with a delayed start and visual transparency effects using different opacity levels.

## Project Overview

This project was created as part of a Web Technology practical assignment to understand and implement CSS animation techniques and opacity styling. It consists of two independent demonstrations:

1. Ball Jump Animation
2. Opacity Property Demonstration

## Features

### Ball Jump Animation

* Animated circular ball movement
* Ball jumps from left to right
* Uses CSS Keyframes
* Animation starts after a 3-second delay
* Infinite animation loop
* Smooth motion effect

### Opacity Property Demonstration

* Demonstrates different opacity levels
* Shows transparency values from 1.0 to 0.2
* Helps visualize CSS opacity behavior
* Simple and clean user interface
